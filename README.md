# Organizador Financeiro

Projeto desenvolvido em Java com o objetivo de praticar programação, organização de código e controle de versão com Git e GitHub.

## Objetivo

Criar um sistema de organização financeira pessoal que permita registrar e acompanhar receitas e despesas.

## Tecnologias

- Java
- Git
- GitHub
- IntelliJ IDEA

## Funcionalidades planejadas

- [ ] Registrar receitas
- [ ] Registrar despesas
- [ ] Listar movimentações financeiras
- [ ] Calcular o saldo
- [ ] Organizar movimentações por categoria

## Status do projeto

Em desenvolvimento. As funcionalidades serão implementadas gradualmente durante o aprendizado de Java.
